# Countries

## Overview

This project offers a comprehensive list of countries for use in web applications. The data is provided in multiple formats to facilitate easy integration based on your requirements.

## Repository Contents

- `countries.csv`: A CSV file containing country names and their corresponding ISO codes.
- `countries.sql`: An SQL script to insert the list of countries into a database.
- `countries-en.html`: An HTML file featuring a dropdown (`<select>`) of countries in English, with lowercase ISO codes as values.
- `countries-fr.html`: An HTML file featuring a dropdown (`<select>`) of countries in French, with lowercase ISO codes as values.

## Usage

1. **CSV Integration**: Import `countries.csv` into your application to access the list of countries and their ISO codes.
2. **SQL Script**: Execute `countries.sql` to populate your database with the list of countries.
3. **HTML Inclusion**: Embed `countries-en.html` or `countries-fr.html` into your web project to add a country dropdown.
